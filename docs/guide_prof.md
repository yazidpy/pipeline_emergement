# Guide Utilisateur : Portail Enseignant (Émargement)

Ce guide accompagne les enseignants pour la gestion quotidienne de l'émargement et le suivi de leurs séances.

---

## 🔒 1. Accès au Portail

- **Lien** : `http://localhost:8502`
- **Identifiant** : Saisissez votre numéro ENS (ex: `ENS001`).
- **Mot de passe** : Par défaut, votre mot de passe est identique à votre numéro ENS.
- **Sécurité** : Ne partagez jamais vos identifiants, ils servent de signature pour la collecte des feuilles.

---

## 📅 2. Mes Séances (Onglet : Prochaines Séances)

Cet onglet liste les cours que vous devez assurer aujourd'hui et dans les jours à venir.

### Étape 1 : Générer la feuille d'émargement
Pour chaque séance, avant qu'elle ne commence :
1. Cliquez sur le bouton **📄 Générer Excel**.
2. Un fichier Excel pré-rempli avec la liste des étudiants inscrits sera créé.
3. Cliquez sur **⬇️ Télécharger** pour l'ouvrir sur votre ordinateur/tablette.

### Étape 2 : Pendant le cours
- Marquez une coche (`O` pour présent, `N` pour absent) dans la colonne correspondante.
- Vous pouvez ajouter des remarques si nécessaire.

### Étape 3 : Dépôt du fichier
Une fois le cours terminé :
1. Enregistrez votre fichier Excel.
2. Dans le portail, utilisez la zone de dépôt située sous la séance correspondante.
3. Glissez-déposez le fichier émargé.
4. Une confirmation **✅ Déposé !** apparaît une fois le transfert réussi.

> [!IMPORTANT]
> Une fois qu'une séance est déposée, les données sont automatiquement envoyées au Dashboard de l'administration pour le calcul du scoring.

---

## 📜 3. Historique & Archives

L'onglet **Historique** vous permet de voir toutes les séances que vous avez déjà effectuées.
- **Filtrage** : Vous pouvez rechercher une séance par date, par mois ou par libellé de cours.
- **État** :
    - **Traité** : Les données ont été validées et agrégées par le système.
    - **Non traité** : La feuille n'a pas encore été déposée ou est en attente de traitement.

---

## 💡 4. Conseils & Aide

- **Format Invalide** : Si le portail refuse votre fichier, vérifiez que vous n'avez pas modifié la structure de l'Excel (ne changez pas les en-têtes ni les ID).
- **Problème d'ID** : Si vous ne trouvez pas votre cours, contactez l'administration pour vérifier votre planning.
